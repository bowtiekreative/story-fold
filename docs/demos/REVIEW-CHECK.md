# A safe edit to try

This file is a small practice surface for Catalyst's review, apply and undo flow.

Open it in **Catalyst → Code**, change this sentence, click **Review change**, and
compare Before with After. **Apply & commit** saves only this file to Git.
**History → Review undo** creates a new proposal that restores the prior text.

The automated browser acceptance test temporarily edits this file and restores
it through the same review and undo controls. Those two commits stay visible.
